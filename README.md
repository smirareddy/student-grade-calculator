
🎓 Student Grade Calculator

📌 About the Project

The Student Grade Calculator is a beginner-friendly Python mini project developed to calculate students' grades based on their marks.

This project demonstrates basic Python programming concepts and helps simplify the process of evaluating student performance.

🎯 Project Objective

The main objective of this project is to calculate and display students' grades based on the marks entered by the user.

✨ Features

- Accepts student marks as input.
- Evaluates student performance.
- Calculates grades based on marks.
- Displays the final grade.
- Simple and easy-to-use program.

🛠️ Technologies Used

- Programming Language: Python
- IDE: Visual Studio Code / Python IDLE

▶️ How to Run the Project

1. Clone this repository:
   
   git clone https://github.com/smirareddy/student-grade-calculator.git

2. Open the project folder.

3. Run the Python file:
   
   python grade_calculator.py
